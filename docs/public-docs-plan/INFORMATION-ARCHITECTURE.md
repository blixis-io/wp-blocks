## Content rules

- Keep procedures tested against a clean installed WordPress fixture and screenshots from real UI.
- Every page states required plan, supported versions and prerequisites when applicable.
- Every example includes complete files/steps, expected output and troubleshooting.
- Avoid undocumented claims of compatibility; link to ADR and relevant source code for developer details.
- Use stable paths for API anchors and redirect old paths on version changes.
