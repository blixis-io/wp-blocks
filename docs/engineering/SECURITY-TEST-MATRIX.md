## GAPS


- T2: locale-specific translator capability checks remain BWB-104.
- T3: full layout and content schema validation remains BWB-043; the current write path rejects duplicate IDs and tree limits only when `root` is present. General per-user preview rate limiting is absent.
- T5: there is no real-WordPress CSS fuzz smoke; the PHP token-set corpus is isolated PHPUnit parity evidence.
- T8: the smoke covers draft isolation but does not explicitly check every cache key dimension.
- T6: forged/replayed-handshake rejection is covered by canvas-bridge unit tests, but is not exercised as an attack in a browser test. Browser-enforced CSP is checked only by the dev-only Herd browser check (`the canvas document has a strict CSP`), not CI; wp-env checks response headers only. The wp-env canvas smoke checks are named above but were not run here (no Docker).
- T7: preview's REST authorization/cache tests and canvas document access smoke do not prove cache behavior through an external reverse proxy; wp-env smoke was not run here (no Docker).
- T9: direct `update_post_meta` mutation by other trusted PHP and concurrency races are outside isolated test proof.
- T17: no built-in durable audit retention policy exists.
- T18: PHPUnit checks bounds but no measured latency/load budget on a real WordPress installation exists.
- T21: per-user/post transient updates and snapshot counting are soft bounds under concurrent requests (transient read-then-write and snapshot count before insert). The rate window lives in an evictable transient, so object-cache eviction resets it. No site-wide aggregate limit or operator alert exists; pruning accounting remains BWB-070 work.
T10, T12, T14, T15, T16, T20 and T22 await their listed future issues or delivery phases.


## Added by BWB-112

- **T1/T2 (identity confusion):** request bodies cannot override route identity (`post_id`, `locale`): `Rest\RouteParams` reads only URL parameters. Evidence: smoke check 'a post_id or locale field in the request body can never redirect a write to another post or stream'. This bug was found by the locale-saving smoke checks (a `locale` field in a content envelope replaced the URL locale and overwrote another stream) and fixed in the same change.
- **T3 (content payloads):** `ContentValidator` bounds and shapes (`LocaleSavingTest::test_content_validation`); locale identity (`LocaleSavingTest::test_locale_identity`, smoke 'content naming another locale is refused with 422').
