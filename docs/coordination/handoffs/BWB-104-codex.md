Questions:
1. Correctness and safety of `set-translation` / `restore-translation`: locale and element checks, orphaned entries, status defaults (`translated` in the default locale, `draft` elsewhere; is resetting a reviewed entry to draft on every edit right? what about editing the default-locale text: should dependent locales change here or only with BWB-105?), `unset` of absent or non-translatable ids, unknown-field and `sourceHash` preservation, prototype-named property ids, key order of the entry, the inverse for first-time entries, interaction with `remove`/`restore` (orphan statuses), document limits, hostile commands (reserved keys, throwing hook), `restore-translation` as a way to smuggle an entry that `set-translation` would refuse (it skips the hook: is that acceptable and documented?).
2. Registry rule: `translationValue` accepts translatable and locale-specific properties and refuses invariant, unknown, prototype-named properties and unknown types; `checkAgainstRegistry` now delegates to it. Any behaviour change for existing documents? Is "unknown type -> not-translatable" right for editing a document whose add-on is gone (the entry stays but cannot be edited)? What about locale-specific values in the default locale and fallback behaviour?
3. Stable ids: the lock file approach (append-only, equality check). Weaknesses (add-ons, renamed types, kinds changing within compatible limits, classification changes that are really migrations)? Is the lock in the right place and format, outside the contract registry's data directories on purpose?
4. Does the design leave room for BWB-105 (source hashes, stale marking), BWB-112 (locale-aware saving) and BWB-114 (inspector) without rework? Anything in the command shape that will be hard to change after release (command names, status semantics, error codes)?
5. Docs accuracy (TRANSLATIONS.md, COMMANDS.md, EXTENSION-API.md, VERSIONING doc edit) and test adequacy: which mutations would still pass (status default swapped, hook ignored, orphan check removed, lock check weakened)? Is the seeded random test meaningful?
