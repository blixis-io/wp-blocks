# Documentation

All project documentation lives here. The repository root keeps only `README.md`, `AGENTS.md` and `CLAUDE.md` (tools expect those there).

| Folder | Contents |
|---|---|
| [`product/`](product/) | PRD, addendum, feature matrix, UX journeys |
| [`architecture/`](architecture/) | System design, WordPress integration, schemas and APIs, [ADRs](architecture/adrs/README.md) |
| [`engineering/`](engineering/) | Git flow, code standards, testing, CI/CD, security, threat model, accessibility, style guides |
| [`roadmap/`](roadmap/) | Roadmap, issue conventions, issue catalogs (`issues.csv`, `issues-addendum.csv`: source of truth for GitHub provisioning) |
| [`agent/`](agent/) | Rules and prompts for AI-assisted development |
| [`github/`](github/) | GitHub Project and issue provisioning runbooks |
| [`coordination/`](coordination/) | Ledger, Codex handoffs and reviews, issue map |
| [`public-docs-plan/`](public-docs-plan/) | Plan for the public Astro Starlight documentation site |

The public documentation site (P10) will live in `apps/docs`; this folder is the internal documentation.
