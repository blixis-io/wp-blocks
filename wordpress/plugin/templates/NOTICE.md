# Bundled template pack notices

The six bundled variable font families are distributed under the SIL Open Font License 1.1. Each family directory contains its upstream `OFL.txt` license.

Images in each template pack's `assets/` directory other than `preview.webp`, and the companion logo SVGs, are locally generated placeholder mock artwork. They are geometric illustrations, are not photographs, and require no third-party attribution. The previews were supplied with the template definitions and remain separate from these generated mock assets.
